Robby: interruptions and clean replies

The internal interruption note is now separate from generated dialogue. Closing requests such as “Danke, das reicht” are recognized as Stop commands.

What went wrong

The old memory entry prepended an English bracketed playback warning to an assistant message. The LLM could copy it; sentence splitting could even turn its internal periods into separate output chunks. Playback uncertainty is now structured metadata and an internal system instruction. Legacy history is cleaned, the known note is suppressed before TTS framing/compact synthesis, and the UI guards against old payloads.

The Stop pipeline uses local multilingual Laya plus direct literal commands, followed by existing acoustic confirmation. “Danke, das reicht” was excluded by the caller's vocabulary gate; “Halt die Klappe” reached Laya but lacked the direct-command treatment. Both paths are corrected without relaxing the background/rival/echo guards.
