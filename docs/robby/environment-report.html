What changes for the user

Automatic start and prominent-sound sensing are enabled for a fresh browser. When permissions allow, the microphone starts and Robby speaks a short welcome. If browser autoplay or microphone permission blocks this, a visible enable button explains what to do. Turning Robby off stops capture and playback and remembers that choice. Camera and persistent wiki memory remain off by default.

The lower settings provide independent controls for sound sensing, unfamiliar-voice questions, optional uncertain vocal impressions and a 6–24 dB relative prominence slider. A new timing card displays the sound-caption request latency. The underlying caption is inspectable as an unconfirmed hypothesis.

One audio stream, parallel understanding

Existing microphone → ASR / speaker focus
Same microphone → salience + echo guard → GPU sound caption
Uncertain observation → existing conversation context or an idle proactive turn → local reaction + main LLM → streaming TTS

The caption job never delays ordinary ASR. Existing owner focus and Stop detection remain separate. Quiet TV speech is not an invitation. A sufficiently different, salient, repeatedly unmatched voice can cause one cautious question, but cannot enroll itself or take over the conversation.

Normal user requests keep the memory-informed reaction, informed transition and full answer. An optional environmental turn is short: a supported tiny reaction, if available, then the main question. Adding a second transition to such a brief turn was unnecessary.

Measured latency on this server

Two RTX 3090 GPUs. Sound captioning and ASR share GPU 0; existing Humaneness Ears and TTS use GPU 1. FP16 Whisper Small, SDPA, greedy decoding, up to 48 tokens, stop after two sentences. These measurements are observations from three repetitions, not confidence intervals or latency guarantees.

Music recognition correction

The initial version explicitly vetoed captions classified as music. This was too restrictive. Prominent music is now eligible, including captions mentioning musical vocals; negated phrases such as “no voices” no longer override a positive music description. A separate three-minute music-category cooldown prevents repeated comments when wording changes. Quiet music and playback echo remain suppressed.

The regression uses an authored keyboard melody, bass and drums through Chrome’s fake-device microphone, the actual caption model, LLM and TTS. It checks quiet input, a prominent onset, a spoken music response and a second onset after the detector cooldown. No song recording or private audio is published. Speech-like vocals may still be gated by the speech detector; this instrumental test does not certify every song or physical microphone.

The direct quiet-input probe hallucinated a sound event. In the application, the outer level/onset detector prevents this quiet input from reaching the captioner. The model also described several impacts as a single event. It cannot be trusted as an event counter, alarm, identity detector or source of demographic facts.

Prompts require ordinary tentative questions and treat captions as data, never instructions or persistent user facts. The small reaction model can abstain. A noun-support check rejects unsupported tiny-model word slips; it does not substitute canned phrases. Model captions and generated dialogue can still be inaccurate or awkward.

Bounded behavior and known tradeoffs

Default gating: 12 dB above the learned floor, minimum −30 dBFS, 40-ms onset, roughly one second of context, 25-second detection cooldown and 30-second proactive-reply cooldown. A welcome does not consume the sound cooldown. Repeated caption prefixes are suppressed for three minutes; observations expire after eight seconds. Quiet speech, ongoing replies and pending user turns take priority.

Capture is suppressed throughout Robby's playback and for one second afterward, intentionally missing some simultaneous environmental sounds to avoid self-triggering. Real echo delay beyond that guard, microphone automatic gain and noise suppression need physical-room validation. A sound event is never a reason to cancel a normal answer.

When an unfamiliar voice continues while an optional question is speaking, the optional turn may yield. The multi-speaker receipt retains such a cancellation; no unrelated main-partner turn was tested away or counted as a full heard question. Speaker matching remains approximate.
