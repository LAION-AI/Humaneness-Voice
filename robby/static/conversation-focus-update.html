Keep the conversation partner, ignore the background

The sentence-streaming mode used to admit every intelligible voice. More seriously, native TYGER BARGE events and literal Stop previews could bypass speaker confirmation entirely. Lowering one global similarity threshold would have increased background interruptions. This update introduces session-local conversation ownership and acoustic admission before both conversation turns and playback cancellation.

Controls and identity memory

Stay with the current conversation partner is on by default near the main controls. Its adjustable partner cosine starts at 0.32, independently of the 0.38 new-voice label threshold. Lower values tolerate more variation but can merge similar voices. The separate 0.55 floor for a nonlexical TYGER interruption avoids treating moderate acoustic similarity as permission to cancel. The label threshold and fast-cue legacy settings are separate controls.

The first clear voice can begin without an introduction. An explicit self-correction such as “Ich bin auch Christoph” links another acoustic mode to the named person. Up to eight variants per person are retained; weak matches never train the reference. Names, embeddings and audio buffers are RAM-only and cleared when the session ends. Embeddings are approximate identity cues, not authentication. A manual Stop button always works independently of voice matching.

Fast and longer evidence

The frozen Nemotron encoder and existing V4 student already supply 320-ms speaker features. The update reuses those features and compares them to prototypes from accepted turns. Longer 3.04-s ECAPA anchors improve the voice reference. A separate 1.28-s recent window, sampled every 640 ms on CPU, checks whether current activity belongs to the partner. This reuses already heard audio and does not wait for a future three-second recording.

Literal Stop requests use the same guard. Weak short-word ECAPA evidence can be supported by temporally consistent native-hop features, with rival/echo separation retained. Very strong recent student evidence can trigger a second, longer ECAPA view. Merely keeping one's mouth open, making noise or matching the previous speaker's long context is not sufficient. Checks are single-flight and revalidate the reply ID before cancelling, so a late result cannot stop a newer answer.

Important limits revealed by the tests

These are deliberately small, correlated synthetic probes, not a false-acceptance-rate estimate for people. In the difficult unknown-voice test, the synthetic Robert Stop can resemble the Christoph anchor in both ECAPA and the feature student. This remains an observed false acceptance; it is not hidden by the functional test result. Registering Robert as a distinct known speaker supplies the rival margin and rejects that probe. Similar or overlapping voices cannot be reliably separated by a threshold alone.

The emotion-profile test is also mixed: the Mira anchor retained all six selected variants, whereas the fixed Idris source did not match six synthesized profile variants at 0.32. A nominal dataset identity does not guarantee that synthesis preserved its acoustic voice. Use actual session speech as the anchor, speak a clear sentence when joining, and explicitly correct a changed voice when necessary. No general speaker accuracy or physical-room guarantee is claimed.

Rolling ownership can stop another voice from extending a pause after a clearly recognized speaker switch. It cannot cleanly unmix two people speaking simultaneously. Strong overlap, a very short unfamiliar Stop, microphone/device artifacts or a failed embedding can remain uncertain. The system then keeps the conversation rather than inventing a new identity; use the manual Stop when needed. No extra GPU model or heavy library was added.

Files and reproduction

conversation_focus.py is the pure ownership policy. sentence_session.py owns async evidence, pause filtering, bounded variants and guarded cancellation. server.py routes native proposals and settings through it. Both director prompts preserve the current speaker/thread without repetitive name questions. The existing camera, avatar, TTS and TYGER network remain available.

python run_unit_checks.py
python prepare_focus_fixtures.py
python validate_conversation_focus.py
uv run --no-project --with playwright --python /path/to/venv/bin/python python browser_conversation_focus.py

The audio diagnostics expect the documented existing public-profile asset cache. Source export contains code and result receipts, not the fixture audio or session embeddings. The browser test needs the configured running ASR/TTS/local-LLM services and one free ASR session.
