Playtime, gentle strokes and optional conversation

Update: 22 October 2026. These are playful screen animations, not motor commands or claims of physical sensation.

Personality intensity slidersSilliness and cuddly personality each have a persistent 0–100% slider, default 100%. Tests compare low/high expression strength, complete carousel turns, zero-level suppression, cooldown scaling, invalid-value rejection and reload persistence. Numeric settings reach the LLM context; arbitrary prompts are not accepted as settings. Current vocal tests include a genuine model-generated “Mmmh, ganz sanft … das ist ja niedlich.” and escalating carousel calls. Optional rides pair the actual audio with carousel → afterglow actions, while invitations pair audio with the puppy pose. The schema and cooldown tests cover both action plans. Model phrasing and acoustic realization remain variable.

Authenticity and boundaries

The director may express a warm, playful personality, appreciation and amusement. It must not invent physical touch sensations, suffering, loneliness, neediness or a need for exclusive friendship. Asked directly about physical feeling, the model explained that the gesture is recognized as an avatar event, not felt bodily. Optional comments may remain silent and are abandoned when the LLM times out or TTS is already busy. These are safeguards and measured samples, not a guarantee of every future model response.

Reproduce

Run python run_unit_checks.py, python personality_director_checks.py, and the Playwright scripts personality_browser_checks.py, avatar_browser_checks.py, personality_live_browser_check.py. Use the existing Python environment plus Playwright and Chrome. The live test uses the single conversation slot; do not run multiple audio tests together. Test fixtures use authored text and synthetic pointer activity, never private microphone recordings.

Files and data

avatar_personality.py validates event context and cooldowns; avatar_actions.py extends the tool schema; static/avatar-actions.js supplies animation and idle scheduling; static/avatar-petting.js handles the hand cursor and stroke detector. The director, TTS bridge, server and UI carry bounded events and optional cancellation. The existing software renderer supplies projected head hit regions. Events remain in session RAM and do not identify a speaker or save biometrics.
