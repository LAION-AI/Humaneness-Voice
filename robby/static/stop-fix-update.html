A pass requires an actual interruption event during a real ≥70-word streamed answer, not merely a recognized transcript. Negative controls require no interruption and no new spoken reply. Every declared case is retained; these are development regression checks, not held-out human accuracy estimates.

Corrections

  • Quiet consonants survive acoustic cropping after foreground admission. Echo residuals use a bounded, held-out-validated nine-tap filter when scalar gain is insufficient; native microphone/TYGER inputs remain unchanged.
  • Short Stop can be corroborated by two acoustic ASR views or by two consecutive distinct decode hops. Old replies, a different addressee and expired audio cannot borrow this evidence.
  • When ordinary short-word verification is inconclusive, the existing frozen encoder and CPU student recheck the command at three fixed frame alignments. The embeddings are averaged, not selected by a favorable score. Existing verified recent voice examples preserve phonetic diversity.
  • Current-person, rival and bot checks remain mandatory. A strong joint-score route or agreement from both live and phase-stable student views is required alongside the classic speaker model. This is not unconditional keyword interruption or authentication.
  • Optional acknowledgment waits up to a bounded quiet-floor deadline for cancelled generation and consumed-command processing. New turns, replies, owner changes and disconnect still suppress it. Stop tails no longer become erroneous new identity requests.

The isolated ASR views now use different fixed leading-silence contexts (0 and 1.28 seconds). This is immediate padding, not additional waiting. The padding ablation records cases where the previous 200-ms context decoded a clean Stop as empty. A very short word with teacher cosine 0.20–0.25 requires both live and phase-stable student cues ≥0.45 plus the stronger rival/bot margin. These correlated cues are not independent probabilities.

The initial enrolled-rival setups in the phase run are retained, including failures before a sufficiently long reply was produced. Separate enrolled-rival controls explicitly speak the current user’s introduction again before the long request; ASR and voice matching still run normally. This checks stop authorization, not general wake-free multi-user request accuracy. An invalid setup is not a successful negative control.

Shared GPU worker cancellation

Robby opts only its own request into cooperative disconnect cancellation. Ordinary Playground calls keep their prior default. The busy flag is held until the GPU thread unwinds, not released by canceling an asyncio wrapper. Measured disconnect-to-idle: 0.48636964708566666 seconds; passed: True.

Actual browser audio playback

HTTPS UI, synthetic MediaStream, real ASR and TTS, with delayed bot echo. Passed: False; acknowledgment playback-complete received: False. The test also checks that old audio is canceled and microphone capture remains active. No physical microphone or human listening is claimed.

Optional acknowledgment

Actual matching reply text AND non-empty streamed PCM observed: True. Silence remains the default; the checkbox enables four rotating local phrases. Explicit wait/quiet commands remain silent.

Reproduce

Run sequentially with the single ASR slot free: python -m speaker_live.stop_regressions, python -m speaker_live.stop_negative_regressions, python -m speaker_live.feedback_check, and python reading_final_regressions.py. Runtime hashes separate current evidence from the retained failed development run. Neither a finite synthetic suite nor a secret-pattern scan proves flawless real-room behavior.
